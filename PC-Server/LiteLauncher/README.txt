StarAudioBridge PC 服务端轻量版
================================

1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击 StarAudioBridge.Server.exe。
3. 启动器会自动检测 .NET 8 Desktop Runtime (x64)：
   - 已安装：直接启动 PC 服务端。
   - 未安装：显示中文提示，并打开微软官方下载页面。
4. 安装 Runtime 后，重新双击 StarAudioBridge.Server.exe。

请不要直接运行 StarAudioBridge.Server.App.exe；它是由启动器调用的主程序。

项目主页：https://github.com/oliverhy/StarAudioBridge
